# BOOTH Outfit Checker

## 🎥 紹介動画

BOOTH Outfit Checker の導入方法と基本的な使い方を動画で紹介しています。

[▶ 紹介動画を見る](https://youtu.be/u9gIltC_oJE)


BOOTH の検索結果を見やすく整理するための **Tampermonkey ユーザースクリプト**です。

一度確認した商品を非表示にしたり、気になる商品だけ残したり、商品画像を大きくプレビューしたりできます。

> [!IMPORTANT]
> 本ツールは **BOOTH / pixiv 非公式**の個人制作ツールです。BOOTH / pixiv とは関係ありません。

## 主な機能

- `☆ 気になる` / `★ 気になる` で候補を保存
- `🙈 非表示` で確認済みの商品を検索結果から除外
- `通常 / ⭐のみ / 全表示` の表示切り替え
- 非表示にした商品を `↩ 元に戻す` で復元
- 非表示にした商品を詰めて表示し、検索結果の空白を抑制
- 商品サムネイルの大型ポップアッププレビュー
- プレビューサイズをスライダー / 数値入力で変更
- 設定・非表示・気になる情報をブラウザの `localStorage` に保存

現在の Userscript バージョンは **3.4.3** です。

## 必要なもの

- Chrome / Edge / Firefox などの対応ブラウザ
- Tampermonkey などの Userscript マネージャー

## インストール

### 1. Tampermonkeyをインストール

使用しているブラウザに [Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo?hl=ja) をインストールします。

1. Chrome ウェブストアで「Tampermonkey」を開く
2. **「Chromeに追加」** をクリック
3. 確認画面で **「拡張機能を追加」** をクリック

インストールが完了すると、Chrome右上の拡張機能一覧からTampermonkeyを確認できます。

### 2. 「ユーザースクリプトを許可」をONにする

Tampermonkeyでスクリプトを動かすために、Chrome側で1か所設定します。

1. Chrome右上の **拡張機能（パズルのアイコン）** をクリック
2. Tampermonkeyの **「︙」** をクリック
3. **「拡張機能を管理」** を開く
4. **「ユーザースクリプトを許可」** をONにする

> この設定がOFFの場合、スクリプトをインストールしてもBOOTH上で動作しません。

### 3. BOOTH Outfit Checkerをインストール

このリポジトリの [`booth-outfit-checker.user.js`](./booth-outfit-checker.user.js) を開きます。

その後、

1. 右上の **Raw** をクリック
2. Tampermonkeyのインストール画面が開く
3. 右上の **「インストール」** をクリック

これで導入完了です。

### 4. BOOTH の検索ページを開く

BOOTH の検索結果ページを開くと、各商品に次の操作が追加されます。

```text
[ ☆ 気になる ] [ 🙈 非表示 ]
```

画面右下には管理パネルが表示されます。

```text
👗 BOOTH 衣装チェック

⭐ 気になる件数
🙈 非表示件数

[ 通常 ] [ ⭐のみ ] [ 全表示 ]

⚙ 設定
```

### 5. スクリプトが有効になっているか確認

Chrome右上のTampermonkeyアイコンをクリックします。

**BOOTH 衣装チェック管理** が表示され、スイッチがONになっていればOKです。

もし動作しない場合は、

- Tampermonkey自体が有効になっているか
- 「ユーザースクリプトを許可」がONになっているか
- 「BOOTH 衣装チェック管理」がONになっているか

を確認してください。

## 使い方

### 気になる

`☆ 気になる` を押すと、その商品を候補として保存します。

登録後は `★ 気になる` になり、もう一度押すと解除できます。

### 非表示

`🙈 非表示` を押すと、その商品が通常表示から消えます。

商品ID単位で記録しているため、同じ商品が別の検索結果に出た場合も非表示状態が維持されます。

### 表示モード

- **通常**: 非表示にしていない商品を表示
- **⭐のみ**: 「気になる」に登録した商品だけ表示
- **全表示**: 非表示の商品も含めて表示

全表示では、非表示商品を `↩ 元に戻す` で復元できます。

### 画像プレビュー

商品画像にマウスを重ねると、大きな画像をポップアップ表示します。

管理パネルの `⚙ 設定` から、次を変更できます。

- 画像ポップアップの ON / OFF
- プレビュー長辺サイズ
- スライダー最大値

## 保存データについて

非表示・気になる・表示設定は、BOOTH ドメインのブラウザ `localStorage` に保存されます。

サーバーや作者へデータを送信する機能はありません。

ブラウザデータを削除した場合や、別ブラウザ・別端末を利用した場合は、保存状態は共有されません。

## 対象ページ

Userscript は BOOTH の検索ページを対象にしています。

```text
https://booth.pm/ja/search/*
https://booth.pm/*/search/*
```

## 更新方法

新しいバージョンが公開された場合は、再度 `booth-outfit-checker.user.js` の **Raw** を開き、Tampermonkey で上書きインストールできます。

## アンインストール

Tampermonkey のダッシュボードから `BOOTH 衣装チェック管理` を削除してください。

Userscript を削除しても、BOOTH の `localStorage` に保存されたデータが残る場合があります。
